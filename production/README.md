# Production API scaffold — НЕ Е АКТИВИРАН
Това е начален сървърен модул за заявките „Поверете имота си на нас“.
GitHub Pages НЕ изпълнява PHP. Файловете трябва да се разположат на сървър с PHP 8.1+ и MySQL/MariaDB, след конфигуриране и тестове.

1. Създайте отделна база и потребител с минимални права; изпълнете sql/001_managed_requests.sql.
2. Задайте IMOTI_CONFIG_PATH към конфигурационен файл ИЗВЪН публичната директория. Използвайте config.example.php като шаблон; пароли/секрети само като environment variables.
3. Публикувайте managed-request.php на собствен HTTPS адрес под същия origin като реалния сайт.
4. Свържете frontend формата към API САМО след активиране на домейна, SSL, публикувана политика за поверителност и end-to-end тест.
5. Административният панел, имейл/SMS уведомленията, CSRF стратегията за реалния домейн, допълнителната anti-bot защита, мониторингът, retention политиката и backup-ите ПРЕДСТОЯТ.
6. Не използвайте този scaffold за реални лични данни, докато не премине security/privacy review.

Защо няма автоматично свързване с GitHub Pages: демонстрацията е публична и статична, няма защитен backend и няма къде да се пазят реални заявки.
